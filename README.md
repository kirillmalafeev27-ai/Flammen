# Flammen — Temple of Trials

Пошагово-таймингованная мини-игра в круговом храме. Восемь перемычек ведут от
внешнего периметра к центральной колоннаде. На каждой перемычке стоят две
каменные статуи (мoai), извергающие огонь по своему циклу. Игрок шагает
тайл за тайлом, рассчитывая безопасные окна. В конце каждой перемычки —
дверь; **две из восьми** дверей правильные, и роли дверей рандомизируются
в каждом забеге.

Огонь — система частиц [Photons2](https://github.com/mkkellogg/Photons2)
(flamethrower-эффект из штатных демок) поверх Three.js.

## Управление

| Клавиша            | Действие                              |
| ------------------ | ------------------------------------- |
| `W` / `↑`          | Шаг вперёд (к колоннаде)              |
| `S` / `↓`          | Шаг назад                             |
| `A` / `D`          | Сменить перемычку (только на периметре) |
| `E` / `Space`      | Войти в дверь                         |
| `R` / `Enter`      | Перезапуск                            |

## Локальный запуск

```bash
npm install
npm start
```

Открыть http://localhost:3000

### URL-параметры (тонкая настройка геометрии под temple.glb)

```
?bridges=8        # сколько перемычек
?tiles=6          # тайлов на перемычку (включая стартовый и дверной)
?rInner=…         # внутренний радиус (по умолчанию из bbox * 0.30)
?rOuter=…         # внешний радиус   (по умолчанию из bbox * 0.86)
?phase=0          # угловой сдвиг перемычек, рад
?y=…              # высота тайлов (по умолчанию из bbox)
?moaiH=1.6        # высота моаи в мировых единицах
?side=1.0         # сдвиг статуи вбок от центра тайла
?mouthY=1.1       # высота сопла огня от пят статуи
?fireScale=0.18   # масштаб огня
?release=20       # release multiplier флеймтрауэра (≥10)
?debug            # debug-метки тайлов и кольца
```

## Деплой на Render

В репозитории `render.yaml` (Blueprint) → New + → Blueprint → подключить
репозиторий → Render развернёт на free-плане.

## Оптимизация под 60fps

Огонь дорог; чтобы не убить FPS, на сцене 16 готовых flamethrower-систем,
но эмиссия включается только в фазе «огонь» цикла каждой статуи и **только
если игрок в радиусе 12 единиц** от статуи. Дальние статуи стоят с
`emissionRate = 0` — буферы выделены, но новых частиц не создаётся.
Декоративные статуи на периметре (между перемычками) не имеют систем
частиц вообще. На всё про всё одновременно активно ~2-4 струи.

Прочее: `pixelRatio` ≤ 1.5; нет shadow maps; ACES-tonemap; текстуры с
anisotropy=4; tone-mapping и fog подобраны так, что визуальное качество
огня не страдает.

## Структура

```
public/
├── index.html
├── js/
│   ├── main.js              — bootstrap THREE + UI
│   ├── game.js              — игровая логика, мир, статуи, двери, ввод
│   ├── flamethrower.js      — обёртка над Photons2 с setFiring(on/off)
│   ├── GltfLoader.js        — Three.js GLTFLoader
│   └── BufferGeometryUtils.js
├── lib/
│   ├── photons.module.js    — собранная Photons2
│   ├── three.module.js
│   └── fflate.module.js
└── assets/
    ├── temple.glb           — модель круглого храма
    ├── moai.glb             — статуя моаи
    └── textures/            — текстуры огня и искр
server.js                    — Express, корректные MIME для ESM
render.yaml                  — Render Blueprint (Node web service, free)
```
