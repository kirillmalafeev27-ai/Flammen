Назовите себя храму

Имя сохраняется локально и используется только для вашего забега.

Загрузка храма...

Выберите уровень немецкого

AI-генерация будет держаться выбранного уровня и не уходить выше него.

Выберите сложность огня

Сложность меняет запас времени во всех огненных циклах. Трудный режим оставляет текущие тайминги.

Выберите лексику забега

Все упражнения будут стараться держаться выбранной тематической области.

Настройте восемь перемычек

Выберите грамматику, затем нажмите на мост. Одну тему можно поставить на несколько мостов; порядок слотов идёт против часовой стрелки.
